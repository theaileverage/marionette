# compare-approaches

Version: 1

Trigger: When uncertainty warrants alternative implementations or independent experiments.

State the common question and discriminating evaluation criteria. Use experiment.create with the same executable checks and explicit candidate instructions; each candidate gets an isolated worktree. Use context selection to preserve independence. Inspect experiment.compare for current verification, diagnostics and artifacts. Gather additional benchmark or research evidence when the common checks do not distinguish quality. Select with experiment.select, an explicit rationale and current evidence references. Stop or revise remaining work deliberately. Selection never merges or discards branches; perform integration and outcome review separately. A changed candidate, criterion or comparison artifact requires fresh selection evidence.

This is optional guidance. The lead may adapt the method while preserving the user objective, permissions, evidence and concurrent work.

Example: Compare an indexed lookup with a scan against the same correctness checks; retain the measured latency results and select only after explaining the workload tradeoff.
