# investigate

Version: 1

Trigger: When the deliverable is knowledge, a diagnosis, an audit or a design decision.

Inspect existing findings first. Choose the questions whose answers could change the decision. Use traceable primary sources where possible, record dates for volatile facts, and distinguish observations from inference. Parallelize independent questions when useful; preserve independent assessments where cross-contamination matters. Save a self-contained report in the assigned workspace and cite it in completion evidence. State unresolved questions and raise blocking choices with decision.open. A recommendation does not grant implementation authority. For authorized promotion, amend the existing objective, revise or add implementation assignments and retain the report as context. Do not discard research artifacts or reset scratch work.

This is optional guidance. The lead may adapt the method while preserving the user objective, permissions, evidence and concurrent work.

Example: For conflicting retention claims, preserve each source and date, identify the effective policy, and state whether an enterprise exception remains unknown.
